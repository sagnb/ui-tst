# Claude sessions

Store one Claude Code session per Markdown file. Each session represents one issue.

Use descriptive filenames such as `001-implement-runtime-config-validation.md`.
If an issue already has an assigned number, use that number instead of creating a new one.

Each file should record:

- Issue title and number (and external link, if available).
- Session date and objective.
- User prompt and authorized scope.
- Claude's implementation report.
- Review findings, requested corrections, and verification results.
- Final status and remaining limitations.

Keep documentation in English. Do not include secrets, credentials, or real environment variable values.

These files are historical records, not instructions to implement additional work.
Creating a session file does not create an issue in an external tracker.
